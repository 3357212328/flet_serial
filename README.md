# OmniPort Studio · 多功能串口/蓝牙/网络调试助手

基于最新 **Flet 1.x** + **PySerial** + **Bleak 3.x** 构建的现代化桌面综合硬件调试工作台，使用 **uv** 进行包与环境管理。

## 核心功能特性

- **串口调试 (UART)**
  - 支持完整串口参数配置：预设与自定义波特率（最高 2,000,000+，含 74880 / 250000 等特殊波特率）、数据位（5/6/7/8）、校验位（None/Even/Odd/Mark/Space）、停止位（1/1.5/2）、硬件/软件流控（RTS/CTS、XON/XOFF）。
  - 支持实时在线切换 **DTR / RTS** 电平（便于一键复位 STM32 / ESP32 等开发板）。
  - 支持 **接收分包超时合并（ms）**，解决高/低波特率下长报文被拆散成多行的问题。
  - 自动展示串口芯片描述、厂商与 `VID:PID` 硬件信息。

- **低功耗蓝牙调试 (BLE GATT)**
  - 支持扫描周边 BLE 设备并实时展示 **RSSI 信号强度 (dBm)**，自动按信号强弱排序，支持一键过滤无名广播信标。
  - 自动识别 Nordic UART (`6E400001`)、HM-10 / JDY (`FFE1`) 等常用透传特征值，同时支持手动下拉切换任意 **Write / Notify 特征值**。
  - 支持自定义 **MTU 分包字节长度**，超长帧自动切片发送。

- **网络串口调试 (TCP / UDP)**
  - 支持 **TCP Client**、**多客户端 TCP Server**（支持客户端列表管理、指定单发或全员广播、主动踢出连接）与 **独立收发端口 UDP**（支持自动锁定最新来源地址回复）。
  - 自动检测并展示本机局域网 IPv4 地址，点击即可复制。

- **增强型终端日志与实时数字示波器**
  - **终端日志**：支持 **文本 / HEX / HEX+ASCII 双显** 实时无损重绘切换，支持 **UTF-8 / GBK / ASCII / Latin-1** 编码实时切换，支持收发方向筛选、关键字实时搜索、暂停滚动、一键复制以及导出为 `.txt` / `.csv` 文件。
  - **实时多通道数字示波器**：基于 `flet.canvas` 硬件加速绘制，自动从 RX 数据流解析 `12.5, 36.8` 或 `temp=25.4, hum=61.2` 等多通道波形，展示实时极值并内置**模拟信号演示**。

- **工程效率套件**
  - **常驻快捷指令库**：支持颜色分类、`HEX/TXT` 模式、编辑管理及 `.json` 指令集导入导出。
  - **发送增强**：支持自动追加校验码（`Modbus CRC16 LE/BE`、`CRC16-CCITT`、`XOR`、`SUM8`）、行尾符选择、定时循环发送、发送历史回溯及**分块文件发送**。
  - **自动应答规则引擎**：支持按文本包含、完全匹配、HEX 字节或正则表达式触发延迟自动回复，轻松模拟从机设备。
  - **内置协议工具箱**：集成 CRC16/CRC32/XOR/SUM8 计算器、IEEE-754 单精度浮点数 ↔ 4 字节大小端 HEX 互转、UTF-8/GBK ↔ HEX 编码互转。

## 使用 uv 运行与管理

```powershell
# 同步项目依赖环境
uv sync

# 启动调试助手桌面端
uv run main.py

# 或通过 Flet CLI 热重载运行
uv run flet run main.py

# 升级 Flet 至最新版本
uv add --upgrade "flet[all]"
```

## 使用 Nuitka 打包单文件发行版 (< 50 MB)

```powershell
# 同步开发依赖（含 nuitka 与 zstandard）
uv sync --dev

# 构建单文件 Windows 可执行程序到 dist/OmniPortStudio.exe
uv run python build_nuitka.py
```
